Make your own custom maps and scenarios!

[h1]Features[/h1]
[list]
  [*] Paint the galaxy in broad strokes, no need to individually place each star and hyperlane
  [*] Then manually tweak the galaxy to get it [i]just[/i] right
  [list]
    [*] Solar systems, hyperlanes, wormholes, and nebulas
    [*] System names
    [*] Unique systems
    [*] Spawn locations
    [*] [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3762808682]Reserved spawns submod - choose where each player / custom AI starts[/url]
  [/list]
  [*] Save and load multiple projects
[/list]

[h1]Instructions[/h1]

This mod does [b]nothing[/b] on it's own. You use it alongside a separate map mod ([url=https://steamcommunity.com/sharedfiles/filedetails/?id=3532904115]see this collection[/url]) or create your map with [url=https://oatmealproblem.github.io/paint-a-galaxy]the Paint a Galaxy web app[/url].
[olist]
  [*] Subscribe to and activate this mod
  [*] Paint, generate a map, and download the txt file in [url=https://oatmealproblem.github.io/paint-a-galaxy]the web app[/url]
  [*] [url=https://steamcommunity.com/workshop/filedetails/discussion/3532904115/755053102163407797/]Add your map to this mod[/url] (easier) or [url=https://steamcommunity.com/workshop/filedetails/discussion/3532904115/529855118245590523/]create your own mod[/url] (better for sharing)
  [*] Start a new game, select "Elliptical" as the galaxy shape and "Painted Galaxy" as the [b]size[/b]
[/olist]

[h1]Known Bugs (will fix)[/h1]
[list]
  [*] Only 1 nomadic AI empire spawns
  [*] Minor issues where vanilla checks for named galaxy sizes
[/list]

[h1]Caveats (minor issues, won't fix / not fixable)[/h1]
[list]
  [*] 1700+ star galaxies require a mod that adds more star names (such as [url=https://steamcommunity.com/sharedfiles/filedetails/?id=2907769573]Just Star Names[/url])
  [*] Sol doesn't get Sol-specific neighbors, eg Alpha Centauri, Barnard's Star
  [list]
    [*] You can use [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3634498401]Local Cluster[/url] for a home system that contains Sol and neighbors
  [/list]
  [*] The "Advanced Neighbors" setting has no effect; advanced AI can neighbor the player
  [*] All precursors are "on" regardless of settings (but [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3039370479]Precursor Selection[/url] does work)
  [*] Nomads with random home systems do not start in a designed-for-nomads system
  [*] Some things additional solar systems, so you'll see some in-game that were not in-app (guaranteed worlds, marauders, fallen empires, some events).
[/list]

[h1]Compatibility[/h1]
[list]
  [*] For Stellaris 4.4
  [*] Should be compatible with most mods
  [*] Modded starting systems must set the "empire_home_system" flag, or they will not work
  [*] Modded origins that change planet classes sometimes have minor issues; please report
  [*] If you are using a modded galaxy shapes, you must select a vanilla shape (eg elliptical).
  [*] Modded precursors are not directly supported, but will work if you use [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3039370479]Precursor Selection[/url]
  [*] Overwrites common/fallen_empires. This is very rare. Built-in compat with:
  [list]
    [*] Ancient Cache of Technologies
    [*] Ethics & Civics: Bug Branch
  [/list]
  [*] Modded event chains that use "neighbor_system" will not work. This is very rare.
  [*] Don't paint stars in the core if playing with Gigastructural Engineering
  [list]
    [*] You can turn on a guide in-app in the "View" menu
  [/list]
[/list]
